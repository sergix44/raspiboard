Requirements & installation notes

Requires PipeWire 0.3.65+, a session manager such as WirePlumber, and a desktop portal backend for file dialogs.

Keep just one downloaded package in your working folder. Download SHA256SUMS from the same release and verify it before installing: sha256sum --ignore-missing --check SHA256SUMS.
